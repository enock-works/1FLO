Os teus dados podem ser apagados Estás a usar a app a partir de um ficheiro local. Muitos navegadores, sobretudo no telemóvel, não guardam (ou apagam) os dados neste modo. Para a biblioteca ficar guardada, abre a página por um endereço https (por exemplo, GitHub Pages). Entretanto, exporta uma cópia.
Estás a abrir dentro de outra app Os navegadores integrados (Instagram, WhatsApp, Facebook, Telegram, etc.) não guardam os dados entre sessões. Abre esta página no Safari ou no Chrome (menu ⋯ ou «Partilhar» → «Abrir no navegador»).

Cópia de segurança

A biblioteca fica guardada só neste navegador. Exporta um ficheiro, ou guarda o link de restauro nas Notas, no e-mail ou nos favoritos: se o navegador apagar tudo, basta abrir esse link para recuperar a biblioteca.
